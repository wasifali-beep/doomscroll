# Roadmap

Plans, not promises. Each line becomes a CHANGELOG entry when shipped.

## v1.0.x — stability
- Fix bugs found in daily use.
- Better error text for provider and network failures.

## v1.1.0 — look and feel
- Proper app icon and splash screen.
- Bundled fonts so the app looks the same offline.
- Larger-text option.

## v1.2.0 — learning paths
- Ordered series per topic (e.g. "HTTP from zero"), with progress.
- Pick up where you left off.

## v1.3.0 — smarter review
- Review cards weighted by past mistakes.
- Weekly summary card: what you learned, what to revise.

## v1.4.0 — focus
- Focus lock: after the daily goal, feed stays closed for a chosen number of hours.
- Optional Android "usage" nudge when other apps are opened too long (research needed).

## v2.0.0 — data
- Export and import progress (backup file).
- Possible change to stored data format, hence the major bump.
